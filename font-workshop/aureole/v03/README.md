# Aureole Display · 第三轮方向优化

目标：更饱满、柔和、有艺术表现的英文标题衬线体。保留上一版供比较；本版使用独立家族名 AureoleDisplay，版本0.200。

调整：o/e字腔与曲线重新绘制，顶部/底部细笔画由约33增加至55单位；竖笔和弧形衬线增厚；a尾部延伸并改善开口；r圆形端点与肩部重画；u、A、C同步调整重量。小写圆形字顶提高至512，较平直顶502超出10单位，是一次光学校正练习。

增加7组试调字偶距：re、ro、la、Cl、au、ol、Au，已检查GPOS内确有7组记录。本机Pillow未带libraqm，无法在该渲染器里切换OpenType字偶距进行对比；样张主要用于轮廓比较，字偶距的应用效果仍需在支持GPOS的浏览器或排版应用中检查。

comparison.png 上面是上一版，下面是本版，同词同字号比较；文字由真实字体渲染。辅助标签采用系统Arial。direction-03.png为本版独立样张。

当前仍为12个字母加空格，尚无完整大小写、数字与标点。TTF和CFF OTF已重新生成、重新读取并通过FreeType加载和渲染；GPOS表已生成。尚未完成系统安装与跨软件验收。

复现：沿用上一级README的依赖，在本目录运行 python design.py。脚本依赖 ../../build.py，会覆盖本版SVG与输出文件。字形定义在design.py，SVG是可检查的生成结果。

学习重点：字重增加不是在渲染图上加粗；应同时调整外轮廓、内字腔、衬线与字距，维护文字整体的黑白节奏。

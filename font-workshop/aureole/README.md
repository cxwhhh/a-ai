# Aureole · 英文艺术衬线方向稿

用户反馈切角机械风不符合预期，改为温暖、书卷气、带艺术表现的衬线方向。当前12个字母：A C a c d e h l n o r u，加空格，共13个映射字符。原Foldline原型保留，新方向单独存放。

direction-02.png中的大号字由本目录生成的TTF实际渲染，辅助英文注释使用系统Arial。Claude仅是比较气质用的样例单词，不是对官方字标的精确复刻。没有导入任何现成字体轮廓。

造型重点：粗竖细横、弧形衬线、双层a、球形r端点、略带倾斜的顶部切口、椭圆字腔。目前设计偏古典编辑衬线，后续可以进一步加重、加宽衬线，或增加不对称细节来增强艺术感。

复现：在父目录依赖之外安装 `python -m pip install skia-pathops==0.9.2 Pillow`，然后运行 `python design.py`。脚本会重写当前方向的SVG、TTF/OTF和样张。修改单字时先修改design.py中的曲线定义；此方向暂不提供保留手改SVG的独立编译入口。构建依赖父目录build.py。

已验证两种字体结构可重新读取，且FreeType能实际渲染。字距未精调、无hinting、未实际安装或跨应用验收。这是少量字符的方向测试字体，不能替代完整英文字体。尚需扩展大小写、数字、标点，并完成度量、字偶距、版本元数据和兼容性检查。

下一次动手练习：从o学三次贝塞尔曲线与字腔，再从n学粗竖笔和衬线过渡，最后在a/r上加入独特收笔。先确定这个方向的视觉感受，再扩展字表。
